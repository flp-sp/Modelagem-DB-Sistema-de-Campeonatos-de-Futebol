# Descrição
Esse projeto cria e configura umas estrutura de banco de dados para um sistema de campeonatos de futebol.

# Tabelas
- Campeonatos
- Times
- Inscricao
- Partidas
- Estadios
- Jogadores

# Tecnologias utilizadas
- PostgreSQL
- PgAdmin
- Git
- GitHub
